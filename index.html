Realidad mixta en el Quest 3

Coloca objetos virtuales sobre las superficies de tu habitación.

  1. Apunta a una mesa, el suelo o una pared: aparece un anillo sobre la superficie.
  2. Pulsa el gatillo (o pellizca con los dedos) para colocar un objeto.
  3. Mantén el botón de agarre (o pellizca cerca de un objeto) para tomarlo, moverlo y soltarlo.
  4. Con controles: A/X cambia la forma y B/Y borra todo.
  5. Con las manos: junta el pulgar con el dedo medio y suelta para cambiar la forma; mantenlo juntos hasta que el círculo se llene para borrar todo.
